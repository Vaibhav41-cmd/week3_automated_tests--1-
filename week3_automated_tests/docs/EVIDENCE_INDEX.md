# Evidence Index — Week 3

This index connects every major claim in the report to a reproducible
artefact in this submission. The Word report embeds the key figures and
code listings, so the evidence can be evaluated even without opening this
folder. To regenerate the execution evidence in a clean checkout:

```bash
pip install -r requirements-dev.txt Pillow  # Pillow only renders the PNG figures
python tools/generate_evidence.py
```
